# AutoFix

Sistema de gestión operativa y financiera para un taller automotriz, desarrollado como proyecto académico de Proyecto Integrador II en la UNAN-León.

## Funciones principales

- Inicio de sesión de usuarios.
- Registro de clientes, vehículos y órdenes de servicio.
- Seguimiento del estado de reparación.
- Gestión de inventario y control de stock mínimo.
- Registro de mano de obra y repuestos utilizados.
- Cálculo automático del total de cada orden.
- Control de pagos y órdenes entregadas.
- Generación de facturas en PDF con ReportLab.
- Generación de reportes operativos.
- Exportación de información.
- Creación de respaldos de la base de datos.
- Uso de hilos para ejecutar procesos sin bloquear la interfaz.

## Tecnologías utilizadas

- Python
- PySide6
- SQLite
- ReportLab
- Git y GitHub

## Requisitos

- Python 3.13 o una versión compatible.
- Las librerías indicadas en `requirements.txt`.
